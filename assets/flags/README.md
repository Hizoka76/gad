# Drapeaux du sélecteur de langue

Images fournies dans la collection locale de l’utilisateur, copiées sans modification :

- `fr_FR.png` : `Version ronde 1/Flag of France.png`.
- `en_US.png` : `Version ronde 1/Flag of United States.png`.

- `es_ES.png` : `Version ronde 3/Spain.png`.

- `pt_PT.png` : `Version ronde 3/Portugal.png`.

- `de_DE.png` : `Version ronde 3/Germany.png`.

- `ja_JP.png` : `Version ronde 3/Japan.png`.

Les PNG sont embarqués dans le binaire par `assets/icons/gad.qrc` ; le dossier d’origine n’est pas requis à l’exécution.

Les fichiers `<locale>.png` sont découverts automatiquement par `scripts/resources.py` et associés aux catalogues `gad_<locale>.qm`. Le fichier `gad.qrc` ne contient que les ressources fixes.
